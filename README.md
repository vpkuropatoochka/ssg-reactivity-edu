# Производное состояние в React и Vue

Учебный статический сайт о вычислении производного состояния на примере списка задач. Материалы сравнивают расчёт при рендере React и вычисляемые свойства Vue. В интерактивной демонстрации число выполненных задач и процент готовности выводятся из отметок.

Сайт собирается Lektor 3.3.14 на Python 3.14. Тексты хранятся в `website/content/`, шаблоны Jinja — в `website/templates/`. Демонстрация и поиск выполняются в браузере, формула записана на MathML.

## Локальный запуск

```sh
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
lektor --project website server
```

Предпросмотр доступен по адресу [127.0.0.1:5000](http://127.0.0.1:5000/).

## Практика Р4

Пуш в `main` публикует сайт на GitHub Pages и по основному адресу Helios. Пуш в другую ветку создаёт отдельный preview в `reactivity-preview/` на Helios. Точный адрес есть в логе шага **Publish to Helios**.

Обе площадки проверяют HTTP 200, HTML-маркер и SHA из `revision.txt`. На Helios файлы сначала загружаются в отдельный каталог версии. После успешной передачи публичная ссылка переключается на новую версию. Если HTTP-проверка падает, workflow возвращает прежнюю ссылку.

Для демонстрации используйте отдельную тестовую ветку.

1. Опубликуйте версию A пушем и сохраните URL и SHA из лога. Затем отправьте в ту же ветку коммит B с пометкой `[skip ci]` в сообщении коммита, чтобы пропустить автоматическую выкладку.
2. Запустите **Build and publish Lektor** для тестовой ветки с операцией `interrupt-preview`. Workflow прервёт передачу B и проверит ранее опубликованные SHA preview и основного сайта. Ожидаемый результат запуска — ошибка со строкой `Transfer interrupted as planned and both public revisions were verified`.
3. Запустите workflow вручную для той же ветки с операцией `deploy`. Убедитесь по логу и `revision.txt`, что опубликован SHA B.
4. Запустите workflow для той же ветки с операцией `rollback`. Проверьте, что снова отдаётся SHA A. Для отчёта сохраните ссылки на запуски и строки с HTTP-статусом и SHA.

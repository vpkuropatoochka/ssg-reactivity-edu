# Производное состояние в React и Vue

Учебный статический сайт о вычислении производного состояния на примере списка задач. Материалы сравнивают расчёт при рендере React и вычисляемые свойства Vue. В интерактивной демонстрации число выполненных задач и процент готовности выводятся из отметок.

Сайт собирается Lektor 3.3.14 на Python 3.14. Тексты хранятся в `website/content/`, шаблоны Jinja — в `website/templates/`. Демонстрация и поиск выполняются в браузере, формула записана на MathML.

## Локальный запуск

```sh
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
lektor --project website server
```

Предпросмотр доступен по адресу [127.0.0.1:5000](http://127.0.0.1:5000/).
